## ADDED Requirements
### Requirement: README P2P git quick-reference wording stays aligned with the public CLI index
The README quick reference SHALL use the same guidance-oriented wording as the public CLI index for the `lango p2p git` family.

#### Scenario: README git wording stays guidance-oriented
- **WHEN** a maintainer updates the README quick reference
- **THEN** the `lango p2p git` lines SHALL describe how to perform the action rather than mixing action-style and guidance-style wording
