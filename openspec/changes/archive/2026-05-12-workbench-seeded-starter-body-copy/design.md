## Overview

This is a copy-level UX consistency fix for the seeded-starter state.

## Design Decisions

### Body copy follows the same phase model as the footer

The workbench now has two explicit phases in both body and footer copy:

- pre-seed: discover how to start
- post-seed: understand how to submit or edit

This removes the last obvious mismatch between what the UI says and what pressing `Enter` will do next.
