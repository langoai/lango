## ADDED Requirements
### Requirement: P2P feature-page git command summaries reflect current CLI behavior
Public P2P feature docs SHALL describe the current `lango p2p git push` and `lango p2p git fetch` behavior truthfully.

#### Scenario: Git command summaries stay guidance-oriented
- **WHEN** the current CLI still delegates live exchange to the running server and tool/runtime flows
- **THEN** the feature-page command summaries SHALL not describe those commands as direct live bundle execution
