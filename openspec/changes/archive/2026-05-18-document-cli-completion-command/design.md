## Context

`lango completion` is generated by Cobra and currently appears in root help under "Additional Commands". The implementation already exists; the drift is in public documentation and the test guard that checks README top-level utility coverage.

## Decision

Treat shell completion as a top-level utility command, not as a new command family with its own dedicated reference page. The CLI reference index is the right home because Cobra owns the shell-specific help and syntax, while the docs only need to surface discoverability and the supported shell targets.

## Approach

- Add `lango completion` to the README command inventory near other top-level utility commands.
- Add `lango completion` to the CLI reference quick reference and core commands tables.
- Extend the existing README top-level utility guard to require the command.
- Add a focused guard for `docs/cli/index.md` so the comprehensive CLI reference cannot omit the root command again.

## Non-Goals

- Do not change Cobra command behavior or generated completion output.
- Do not add a dedicated completion documentation page unless the command gains Lango-specific behavior beyond Cobra defaults.
- Do not rewrite the full CLI reference.
