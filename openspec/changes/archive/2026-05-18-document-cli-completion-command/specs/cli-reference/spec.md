## MODIFIED Requirements

### Requirement: CLI reference covers implemented root commands

The public CLI reference SHALL document implemented root commands that appear in `lango --help`, including operator utility commands generated by Cobra.

#### Scenario: Root completion command is documented

- **WHEN** `lango --help` exposes `completion` as an additional command
- **THEN** `README.md` and `docs/cli/index.md` SHALL include `lango completion` with a user-facing description
