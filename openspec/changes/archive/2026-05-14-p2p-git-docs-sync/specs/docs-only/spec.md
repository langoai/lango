## ADDED Requirements
### Requirement: Public quick-reference docs include implemented P2P git commands
README and the public CLI quick reference SHALL include the implemented `p2p git` command family.

#### Scenario: P2P git commands are discoverable from top-level docs
- **WHEN** a reader consults the README command summary or `docs/cli/index.md`
- **THEN** they SHALL find `lango p2p git init`, `log`, `diff`, `push`, and `fetch`
