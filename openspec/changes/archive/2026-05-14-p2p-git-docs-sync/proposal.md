## Why

The `p2p git` command family is implemented and described in the dedicated P2P CLI page, but it is still missing from the public quick-reference surfaces in the CLI index and README.

## What Changes

- add `p2p git init/log/diff/push/fetch` to the public CLI quick reference
- add the same command family to the README command summary

## Impact

- improves discoverability for the server-backed P2P git workflow
- reduces mismatch between the detailed CLI page and top-level public summaries
