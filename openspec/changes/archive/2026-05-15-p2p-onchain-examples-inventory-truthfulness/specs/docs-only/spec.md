## ADDED Requirements
### Requirement: P2P on-chain examples index reflects the shipped example set
The `p2p-onchain-examples` main spec SHALL include a numbered summary for each shipped example directory.

#### Scenario: Shipped `p2p-trading` example is listed
- **WHEN** the repository ships `examples/p2p-trading`
- **THEN** the numbered example summaries SHALL include `p2p-trading`
