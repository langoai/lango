## ADDED Requirements
### Requirement: P2P feature-page CLI intro reflects mixed command modes
Public P2P feature docs SHALL describe the current `lango p2p` command families truthfully.

#### Scenario: Team/workspace/git guidance surfaces stay distinguished
- **WHEN** `team`, `workspace`, and `git` command families are still guidance surfaces for the running server
- **THEN** the feature-page CLI intro SHALL not describe the whole command list as ephemeral-node execution
