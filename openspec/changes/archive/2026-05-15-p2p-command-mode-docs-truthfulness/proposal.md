## Why

The public P2P feature page still framed the whole `lango p2p` command list as ephemeral-node execution, but the current `team`, `workspace`, and `git` families are server-backed guidance surfaces rather than full direct live control. That top-level wording overstates the current CLI.

## What Changes

- sync the P2P feature-page CLI intro to the current mixed command-mode reality
- extend the executable docs guard so stale all-ephemeral wording cannot silently return

## Impact

- public docs better match the actual CLI UX
- reduced operator confusion when scanning the P2P command overview
- stronger regression protection for feature-doc drift
