## MODIFIED Requirements
### Requirement: Cockpit feature docs describe the Settings and Status operator surfaces
The public cockpit feature reference SHALL describe the current Settings and Status pages beyond simple roster availability.

#### Scenario: Cockpit feature page describes Status interaction model
- **WHEN** the public cockpit feature reference describes the Status page
- **THEN** it SHALL explain that the page is read-only and does not expose cockpit help-bar bindings
- **AND** it SHALL mention that the page refreshes automatically while active
