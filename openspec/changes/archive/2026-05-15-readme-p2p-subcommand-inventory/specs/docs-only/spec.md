## ADDED Requirements

### Requirement: README P2P inventory uses current subcommand slices
The README internal CLI inventory SHALL describe the current P2P subcommand slices rather than only broad family names.

#### Scenario: Broad family-only shorthand stays removed
- **WHEN** a maintainer updates the README internal tree inventory
- **THEN** it SHALL describe the current firewall, session, sandbox, workspace, git, provenance, team, and ZKP subcommand slices
