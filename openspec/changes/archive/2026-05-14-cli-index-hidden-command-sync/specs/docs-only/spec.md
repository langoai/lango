## ADDED Requirements
### Requirement: CLI quick reference includes implemented KMS and P2P operator commands
The public CLI quick reference SHALL include the implemented KMS wrap/detach and P2P workspace/provenance exchange commands.

#### Scenario: CLI quick reference exposes the implemented operator surfaces
- **WHEN** a reader consults `docs/cli/index.md`
- **THEN** they SHALL find `lango security kms wrap`, `lango security kms detach`, `lango p2p workspace ...`, and `lango p2p provenance push/fetch`
