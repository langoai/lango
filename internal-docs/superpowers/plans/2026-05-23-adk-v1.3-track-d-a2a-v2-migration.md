# ADK v1.3 Track D — A2A v2 Immediate Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement task-by-task.

**Goal:** Switch `internal/a2a/remote.go` (and its test) from `google.golang.org/adk/agent/remoteagent` (v1, now `Deprecated`) to `google.golang.org/adk/agent/remoteagent/v2`. Use the new `AgentCardProvider` helper instead of the removed `AgentCardSource` field. Keep `internal/a2a/server.go` unchanged — it is a custom AgentCard JSON server, NOT an ADK A2A executor.

**Architecture:** Tiny, surgical migration. Replace one import path + replace one `A2AConfig` field. Confirm `server.go` is out of scope (does not use `adka2a`).

**Tech Stack:** Go 1.23+, `google.golang.org/adk@v1.3.0`, branch `feature/adk-v1.3`.

**Spec reference:** `internal-docs/superpowers/specs/2026-05-23-adk-v1.3-capability-first-design.md` §4 Track D.

**Pre-flight findings (informing scope):**

1. **`internal/a2a/server.go` is NOT an ADK A2A executor.** It serves Lango's custom `AgentCard` struct (with P2P/pricing/ZK extensions) at `/.well-known/agent.json`. It imports `google.golang.org/adk/agent` only for the `agent.Agent` interface type (used as a parameter type). No `server/adka2a` import. **No migration needed.**

2. **`internal/a2a/remote.go` uses `agent/remoteagent.NewA2A` exclusively.** Sets 3 fields on `A2AConfig`: `Name`, `Description`, `AgentCardSource`. `AgentCardSource` does not exist in v2's `A2AConfig`; use `AgentCardProvider: remoteagent.NewAgentCardProvider(url)` instead.

3. **`internal/a2a/remote_test.go`** uses `remoteagent.A2AConfig` as a function-signature parameter type via the `newRemoteA2AFn` indirection pattern. The signature `func(remoteagent.A2AConfig) (adkagent.Agent, error)` is identical between v1 and v2, so changing the import alone migrates the test.

4. **v2 backward-compat:** the v1 `agent/remoteagent` package in v1.3 is marked `Deprecated` but still functional (it delegates to v2 internally via a compat shim). Lango chooses immediate v2 transition per user constraint.

**Pre-flight context the engineer needs:**

- Branch: `feature/adk-v1.3`. Tracks 0 and A are in the working tree as uncommitted changes; do not disturb them.
- Baseline (post-Track A): 197 ok / 2 fail (`internal/p2p/gitbundle`, `internal/testutil`).
