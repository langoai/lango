# ADK v1.3 Track A — Wrapper Slim-Down Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Slim the `internal/adk/` wrapper by deleting the unused `plugin.go` spike artifact, confirm the OTel attribute rename is a no-op for Lango, and document the boundary between Lango's persistence-layer ThoughtSignature handling and upstream's streaming-layer aggregation.

**Architecture:** Three sub-tracks (A1, A2, A3) from spec §4 Track A — each is now a documentation or deletion task, not a transformation. Pre-flight investigation showed A1's "removal" would have broken persistence (upstream change is orthogonal); A2 has zero production consumers; A3 has zero emitter sites in Lango.

**Tech Stack:** Go 1.23+, `google.golang.org/adk@v1.3.0` (already on `feature/adk-v1.3`).

**Spec reference:** `internal-docs/superpowers/specs/2026-05-23-adk-v1.3-capability-first-design.md` §4 Track A.

**Branch:** `feature/adk-v1.3` (continued from Track 0).

**Pre-flight findings (informing this plan, not the spec author's view):**

1. **A1 — ThoughtSignature.** The spec said: "v1.3 stream_aggregator.go propagates ThoughtSignature across streamed parts… remove the manual round-trip at BOTH call sites." Verified against `$GOMODCACHE/google.golang.org/adk@v1.3.0/internal/llminternal/stream_aggregator.go:40,107,143-146`: that code propagates `ThoughtSignature` *between Parts within a single LLM response stream* (streaming layer). Lango's `internal/adk/state.go:445-477` propagates `ThoughtSignature` *between ADK runtime types and Lango's internal storage* (persistence layer). The two concerns are orthogonal. Removing Lango's code would break thought_signature continuity across session restarts and history reloads. **Decision: KEEP. Update spec to reflect this.**

2. **A2 — plugin.go.** 290 LoC at `internal/adk/plugin.go`. Banner explicitly marks it spike-only ("SPIKE ONLY — not wired to production runtime"). `grep` for production consumers (`adk.NewEventLoggingPlugin`, `adk.NewBeforeToolLoggingPlugin`, `adk.WithPlugins`) returns zero hits in `internal/app/`, `cmd/`, or anywhere else outside the spike's own test. One test file (`context_helpers_round_trip_agent_and_child_session_test.go:140-179`) exercises the spike's plugin constructors. **Decision: DELETE plugin.go and the dependent test fragment.**

3. **A3 — OTel reasoning attribute.** Upstream renamed `gen_ai.usage.experimental.reasoning_tokens` → `gen_ai.usage.reasoning.output_tokens`. `grep -rn "experimental.reasoning|gen_ai.usage|reasoning_tokens"` over the Lango codebase returns **zero hits**. **Decision: confirmed no-op — record the verification.**
